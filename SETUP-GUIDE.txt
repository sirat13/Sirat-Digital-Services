PART A — CREATE THE DATABASE (SUPABASE)
1. Open https://supabase.com/ and create a free account/project.
2. Create a project named sirat-digital-services. Save the database password privately.
3. In your project, open SQL Editor > New query.
4. Open supabase_setup.sql from this package, copy all its contents, paste into SQL Editor and click Run.
   This creates the tables, public read access, private owner-only admin policies, order inbox and proof image storage.
5. Open Project Settings > API (or API Keys, depending on dashboard layout).
6. Copy the Project URL and the anon/public key. Do NOT copy the service_role/secret key.
7. Open config.js and replace:
   PASTE_YOUR_SUPABASE_PROJECT_URL_HERE
   PASTE_YOUR_SUPABASE_ANON_KEY_HERE
   with your project's Project URL and anon/public key.

PART B — CREATE YOUR PRIVATE ADMIN LOGIN
1. In Supabase, open Authentication > Users > Add user.
2. Create a user using your owner email: siratakanda06@gmail.com and a strong password you keep private.
3. If the dashboard asks to confirm the email, use the confirmation option there or complete the email confirmation.
4. The SQL policies authorize only this exact email to edit the site and read orders. Do not share the password.
5. Admin page is opened from the “Admin Login” button on your public website.

PART C — PUBLISH FOR FREE WITH GITHUB PAGES
1. Open https://github.com/ and create/sign in to your account.
2. Create a new PUBLIC repository named sirat-digital-services (public is required for free GitHub Pages on GitHub Free).
3. Upload all package contents to the repository root:
   index.html, config.js, supabase_setup.sql, SETUP-GUIDE.txt, and the assets folder with its images.
4. Commit the files.
5. In the repository, open Settings > Pages.
6. Under Build and deployment, select Deploy from a branch; choose branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. The site address will be:
   https://YOUR-GITHUB-USERNAME.github.io/sirat-digital-services/
   Replace YOUR-GITHUB-USERNAME with your GitHub username.
8. Open that URL in Chrome to test it.
